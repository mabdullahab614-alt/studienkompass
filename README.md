## 🎯 What Is This

<img align="right" width="240" src="https://capsule-render.vercel.app/api?type=venom&color=0:e8b923,100:c0392b&height=120&section=header" alt="decorative divider"/>

Studienkompass is a **client-side eligibility checker** for Pakistani students applying to English-taught Bachelor's programs at German public universities — a process usually scattered across dozens of university pages, uni-assist rules, and APS requirements.

**How it works:**

| Step | Action |
|:--:|:--|
| 1️⃣ | Enter your academic record — Matric %, FSC %, IELTS / TOEFL / SAT / TestAS, German level, preferred field |
| 2️⃣ | Get scored against **130+ public universities** |
| 3️⃣ | See a ranked list tagged 🟢 **Eligible** · 🟡 **Conditional** · 🔴 **Not Eligible** |
| 4️⃣ | Each result shows *why* — e.g. `FSC 86% ✅` · `IELTS 7.0 ✅` · `TestAS — not taken` |

> ⚠️ **Honesty note:** university and city names are real, but every threshold shown (percentages, IELTS/TestAS bands, fees) is a *modeled, illustrative pattern* — not an officially verified figure. Always confirm current requirements on the university's own page.

🔐 **Privacy by design** — everything runs in your browser. Nothing is stored, nothing is sent to a server.

## 🛠️ Tech Stack

<div align="center">

<img src="https://skillicons.dev/icons?i=html,css,js,github" alt="HTML, CSS, JavaScript, GitHub"/>

**Plain HTML + CSS + vanilla JavaScript — zero frameworks, zero build step, zero dependencies.**

</div>

- 🎨 **CSS** — all layout, styling, and responsive breakpoints hand-written in `style.css`
- ⚙️ **JavaScript** — UI/state logic in `script.js`, kept fully separate from the eligibility math in `scoring-engine.js`
- 🧪 **Testing** — a from-scratch test runner (`test-framework.js`) instead of an external library

## 🧪 Testing

No external test framework — `test-framework.js` is a minimal, hand-built `assert` / `describe`-style runner.

1. Open [`test-runner.html`](./test-runner.html) directly in a browser
2. The suite in `scoring_tests.js` runs automatically and reports pass/fail
3. Covers edge cases like a field left at `0` / `None` (test not yet attempted) — scores should degrade gracefully, not break

## 🚀 Getting Started

No build step, no `npm install` — it's static HTML/CSS/JS.

```bash
# 1. Clone it
git clone https://github.com/mabdullahab614-alt/studienkompass.git
cd studienkompass

# 2. Open it directly...
open index.html          # macOS
start index.html         # Windows

# ...or serve it locally
python -m http.server 8000
# then visit http://localhost:8000
```
